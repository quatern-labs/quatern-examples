# 05 · Navigation

Plan a path on the map Quatern built from the capture, deploy it in the
simulator, and confirm the localizer's drift stayed in bounds. There are two
built-in worlds with different difficulties. A third, `warehouse_aisle`, works
the same way.

| Example | What it shows | Needs |
| --- | --- | --- |
| [`01_hallway`](01_hallway/) | A 13 m corridor with repetitive door frames, which is hard for a localizer. A Jetson rover drives 8 m down it. | Nothing |
| [`02_room`](02_room/) | A living room with a kitchen island in the middle. A TurtleBot 3 Waffle plans around it. | Nothing |
